# 问题解答

1. 在卦中必须是独爻发动才能是绝处逢生吗？
	不是的。就算是一个静爻，月来绝它，如果日来生，这个也算绝处逢生。或者是别的动爻来生扶它，也算是绝处逢生。
2. 为什么卯木戌土相克但是相合？
	比如有些情侣在一起三天一小吵，五天一大吵，但就是不分手对吧，或者是嘴上说着特别讨厌自己的工作，但是有跳槽的机会也不走，这种情况就是克合的象。
3. 墓库的旺衰影响其能力吗？
	会的。比如一根爻在卦中发动，想去收其他静爻入他的墓库，但是他本身墓库是休囚的情况下，那他发动也没有这个能力去收其他的静爻入墓。
4. 日月拓展
	月可以想象成为父亲的那种感觉，就是为父则刚，那种大环境大趋势对你的影响，然后日辰，可以想象成为母亲，那种温柔的感觉，就是会更加注重细节上的一些东西。日辰有修正的作用，比如把爻冲起来暗动以及绝处逢生，还有可能是日破跟冲散的可能。一根旺相的静爻被日辰冲就是暗动，一根旺相的动爻被日辰冲，就是越冲越动。休囚的爻被日冲，冲也动不了。月令是主长期的能量，日辰是主短期的能量。如果一根爻在月上旺相，但是在日辰休囚的话就可以说这件事情在最近不是很顺，但是长期来讲这件事还是可以做的。
5. 为什么说月令只有把卦中的爻收入月墓中的象，但是不会真正把它的收入月墓
	因为月令只讲大环境大趋势，它不会去管到非常细节的东西。
6. 断卦流程
	先梳理逻辑，取用神看原神，忌神旺衰，再以六亲分析取象，看生克冲合空亡，然后再看十二长生，答案是看不同的问题和卦，我们会以卦理或者是卦象断，或者是两者结合断。


# 进、退神

- 含义：指有一个爻发动之后，化出的这个爻还是在同五行属性上，往前走就是化进神，往后退就是化退神。(一定是同五行)

比如寅木在卦中发动，化出卯木，这种情况就叫做化进神。
	酉金在卦中发动，化出申金，这种情况就是化退神。

![[进退神.png]]

亥水化子水就是化进神、午火发动化巳火就是化退神；辰土化未土就是化进、辰土化丑土就是化退；必须是同属性的！

进神：成长、发展、上进、采取行动、主动、变大、不断的、扩大、膨胀、走远

退神：退缩、淘汰、后悔、倒退、衰弱、返回、萎缩、退化

如果求测人来测做生意：然后妻财爻化进神，就代表财源滚滚，挡都挡不住。
然后占阴宅风水（墓地）：子孙化进就是子孙一代比一代强
占工作官鬼爻化进，就是会一路升官升职

如果占婚姻，对方化退，那就代表感情关系往后退，越来越差。
如果测行人化退，那就代表人会回来，然后化进神就是越走越远，就回不来了。

爻化进退神的力量是无法阻挡的，就如果在卦中，当时能量就休囚的话，那等旺相就会化进。月破的化，出月解就会化进。
就好比一个人他在一直在尝试，就大环境对他不利的时候，他没有办法，但是大环境稍微对他有利一些的时候，他就一飞冲天了，化进神退神就是这样的象。如果要化进神，那么空破休囚冲合怎么样对他来说都不影响，他最终还是要化进；

若是化退神，能力也是阻挡不了的。但是有几种情况，他在短期的时候是不退的，第一个就是合而不退（冲的时候退），就是有日月或者其他动爻来合它的时候，那它就不退，但是冲的时候，那就是一个应期。然后旺而不退，就是说现在他这个爻旺相，但是他现在自己本身想化退，那一根爻总有休囚的时候，那他在休囚的时候就会化退。

# 反吟、伏吟

反复折腾、来回不定、来回、成而败、败而成、波折多、不稳定

**反吟**：就是变爻去冲本位动爻。（卯 -> 酉）
它就代表反反复复，无论做什么事情都一样。
占出行就是会反复来回走或者在外面漂泊不定。
占工作升职，官鬼旺相就算升官了也会掉下来。
占感情就是分分合合，来回拉扯不稳定。
爻占心理状态就可以说这个人拿不定主意，内心反复挣扎。
这个就是反吟的象。如果用神参与到了反吟的话，那基本可以拿凶来断了，这件事情不会顺利。
那反反复复什么时候是一个头呢？因为反吟的本质就是回头去冲，那合的时候就是一个应期。
就比如说卦中卯木发动化出酉金，那么辰月辰酉相合的时候就解开了。

**伏吟**：就是在卦中发动的爻，画出跟本位动爻一样的地支。（寅 -> 寅）
伏吟就是困住、困境、原地踏步、固执、内耗
而解开伏吟就是要冲，不过要注意一下就是不是所有的反吟跟伏吟都是可以解的。
首先还是要看用神在卦中有没有气，就如果用神休囚的话，那反吟伏吟就算去冲合也是没有用的。
在伏吟里，这就好比一个人在牢笼里，他什么事情都做不了，但是他本身就不想做事，你把牢笼打开，他还是一样不做事。

# 原神 有用/无用

带入爻位来感受（旺相 = 有用、 休囚=无用）

## 有用
- 原神 值/临 日月
- 原神动化 回头生/进神
- 原神 长生/帝旺 于日辰 （日主短期）
- 原神与忌神同动 （忌神生原神来通关）贪生忘克
- 原神旺动，临空化空

## 无用
- 原神休囚 又逢空月破
- 原神休囚 又化退神
- 原神休囚 又 动而化 回头克/绝（十二长生）/破/散（发动被日辰来冲这个变爻或者动爻）
- 原神入三墓（日墓、动爻之墓、变爻之墓）变爻之墓：本身发动化出了自己的墓库
- 原神囚而无气





# 忌神 有用/无用

## 有用

- 忌神 值/临 日月
- 忌神遇日月/动爻生扶
- 忌神旺动，临空化空
- 忌神长生帝旺于日辰

## 无用
- 忌神休囚不动
- 忌神入三墓
- 忌神休囚化退神/绝/回头克/破/散
- 忌神与原神同动
