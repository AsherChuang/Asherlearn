

# 卦中元素介绍

![[六爻卦.png]]

动爻：在卦中发动的爻 —— 子孙未土 可以去作用其他静爻

变爻：动爻变出的爻——妻财申金 变爻主要是作用本位动爻

变爻有作用于卦中其他爻的象

外卦：卦上面的三根爻

内卦：卦下面的三根爻

本卦：左侧原本的卦

变卦：右侧变出的卦

世爻：代表求测人自己

应爻：代表他人或者占彼此行事（也就是占竞争的时候，应爻代表对手）

# 冲合

![[相合相冲.png]]

冲：不久、冲散、不安、分离、争斗

合：长久、合住、合作、纠缠、和好

## 月令
月令冲卦中的爻，统一叫作月破，代表这根爻暂时没有能量了。

但是如果这跟爻受日来生或者卦中其他爻来生扶它，那就代表这根爻还是有根的，这根爻以后还是会有用。合也是同理

冲：月破 （有根就有用）

合：合旺（有根）

## 日辰

冲：冲起（暗动，这根爻本身是旺相，那么冲起后就和动爻效果一样，可以作用其他静爻）/ 冲空填实

如果这根爻本身是旺相的，它是有根的，但是它被日辰连冲带克，比如子午相冲，子水是去克午火的，如果是子日，然后午火是旺相，这种连冲带克，它也是叫暗动，但是这种情况只能冲起百分之50左右的能量。

如果这根爻本身就非常休囚，那么日辰去冲它也是没有用的，所以可以说它有想动的象，但是它自己的能力不足，日辰去冲它也冲不起来，有种烂泥扶不上墙的感觉。

如果是日辰去冲卦中的爻，如果这根爻刚好是旺相且空亡的状态，那这种情况就叫做冲空填实。

合：合绊、合旺

这里也可以这样理解：值日为百分百，但是被申金在寅月是囚，综合一下还是有百分之67.5%的能量，但是这个月暂时冲没了，但是出了这个月还是百分之67.5%的能量。

# 旬空/空亡

空心，心里没底、不在、不自信，虚伪，失去依附……

如果有个人来测他的事业，然后世爻空亡的话，那就可以说这个人自己心里没有底，或者是他不自信。

比如说求测人想找一个人，想问对方在不在家，摇出来是应爻空亡，那就代表对方不在家。
如果妻财持世，原神为子孙，子孙空亡，子孙代表思维想法，原神也代表思维想法，那么这就代表这个人脑袋空空、魂不守舍，被什么东西伤到了

木空则朽，火空则发，土空则陷，金空则鸣，水空则流

这里空亡不主吉凶，比如女测感情，我们看官鬼酉金，如果官鬼酉金旺相且空亡，就可以说他唱歌或者说话声音很好听，因为他是旺相的金，金空则鸣。如果官鬼酉金空亡，酉金是休囚的话，就可以说他唱歌声音很大，但是声音不好听，唱歌总跑调。

所以空亡不主吉凶，吉凶还是要看卦理，看卦中的能量走向，生克冲合。
空亡主要是看象，把这个图片生动的描述给求测人听。

比如占彼此之形势，和对方竞争，应爻旺相的土空亡，就可以说对方城府很深，会设置很多陷阱。
占财的话，妻财亥子水空亡，就代表钱像水一样流走了。

## 进阶：空亡有几种情况是不空的

1. 旺相被日辰冲。冲空填实为不空。
2. 还有如果该爻是独动的话，那在卦中它是唯一一个发动爻，那他也是不空的。但是如果它是休囚独动，它短期也还是不空，但是如果测长期的事情，它还是得空。
3. 有句话叫做：旺不为空，动不为空。空化空不为空，然则还是空（从一个空亡的爻化为空亡的爻，那么不为空，但是还是空）比如失恋之后很伤心，然后被外部的力量救赎了，但是失恋的伤疤还在。
4. 化解是永远针对将来的，而未来永远在自己手中。化解无非就是一个身份互换，把你从接受世界反馈的人，变成你做事，然后让世界给你反馈。比如现实中本来这一部分事情要发生，但是你知道这一系列事情要发生之后，你自己去主动改变一些东西，那结果就肯定是不一样的。
5. 空者，非无也，未成也。比如爻在旺相的时候空亡，就是在告诉你应期，去冲空填实。
6. 空而旺者，有名无实；空而动者，有始无终。比如测一个合作伙伴，旺相并且空亡，就是虚假的名头，没有真正的实力。然后空亡的人去发动就是有始无终。

# 取用神

取显象：
比如说一个人要去一个地方求财，他现在在哪里，要去哪里，路上可能做什么事情，把这些东西都安在卦上。他最后想要在那里求财呢还是定居呢。如果是用神两现的话，就取那个跟已知条件最符合的那个用神来看，不过这个也是有一个系统的先后顺序。

1. 动爻
2. 空亡、月破之爻
3. 逢冲、逢合、暗动之爻
4. 居世、应
5. 爻位/六神取象
6. 兼看



# 十二长生

![[十二长生.png]]

1. 冠带、临官、衰、胎、养一般用的不多
2. 子午卯酉是桃花位，真桃花会有冲击、假桃花没有那种冲击
3. 如果男测感情，在这个卦里妻财爻跟应爻相合沐浴，那就代表他们抱在一起洗澡，那这种情况就是说这个女的，她出轨了。
4. 病在疾病里面挺显像的。
5. 死、墓、绝就是很休囚的，比如在一个卦里面独爻发动化死地，化绝地，那就说这个卦从象上来看是非常凶险的，如果化绝地，在卦中又有爻来暗动生它，或者说日辰来生它，这种情况就叫做绝处逢生。就可以跟求测人说，刚开始感觉会特别糟糕，就一点希望也没有的那种感觉，但这之后一定会有转机，因为绝处逢生了。墓的话是六爻里面用到最多的一个象，四个土，辰戌丑未，墓代表收藏收埋，然后如果原神入墓，就是代表他的思维想法关起来了。卦中的爻是可以入日墓或者入月墓的，不过入月墓只有入月墓的象，就是说这个月想把你这跟爻收起来，但是它其实是收不住的，跟之前的变爻有作用于本卦中其他爻的象是差不多的，就是说它想做用于你，但是它现在没有能量作用你。所以说它就是一个想法而已，就是一个象。
6. 当一个爻在卦中的能量非常分散的时候，比如在本卦中两现，然后在变爻中再找一个，就是有三个或者三个以上一种属性的情况下，如果是做事的话肯定是做不成功的这种时候就需要一个墓库来收藏它们。就比如说，如果是一个人求财，出现了三个妻财酉金（出现任何三个财爻也是一样的），就可以说现在的钱非常分散，等到丑月的时候，就可以把这些钱全部收起来了。所以墓也是一种应期，当一种属性被收到一个墓库里面的时候，你冲开这个墓库的时候也是一个应期。
7. 未是木的墓库；戌土是火的墓库；丑土是金的墓库；辰是水土的墓库。
