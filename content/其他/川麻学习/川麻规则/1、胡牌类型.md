
# 麻将胡牌牌型结构（川麻）

## 一、正常牌型

结构为：3 + 3 + 3 + 3 + 2 五搭牌 

2为将牌，3可以为顺子或刻子

顺子：3张牌相连

刻子：3张牌相同

注意这里图片并不是川麻胡牌类型，因为有三种花色，但是结构相同

![[胡牌牌型.png]]

牌局中操作：

1. 摸牌 摸了就要打牌 摸一张打一张
2. 碰牌 其他玩家打出八条，可以碰。碰完打一张
3. 杠牌 别人打出或者自己摸到，杠完摸牌再打出一张牌
4. 胡牌 最后最多有18张牌（杠4次），番数最大，十八罗汉
5. ~~不能吃牌！❌~~
